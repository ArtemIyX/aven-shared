# @wellsaik/aven-vue

Vue components for Aven. Install `@wellsaik/aven-vue`, `@wellsaik/aven-shared`, and Vue 3. Import `{ AvenText }` from `@wellsaik/aven-vue` or `@wellsaik/aven-vue/AvenText`; explicitly import `@wellsaik/aven-shared/tokens.css` and `@wellsaik/aven-vue/style.css`. See the [repository README](https://github.com/ArtemIyX/aven-shared#readme) for props, customization, and migration.
