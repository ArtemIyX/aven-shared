# @wellsaik/aven-shared

Framework-independent Aven tokens and styles. Import `@wellsaik/aven-shared/tokens.css` (or `colors.css` for all domains) and optionally `base.css`. Domain subpaths: `finance.css`, `charts.css`, `diagrams.css`, `gradients.css`. See the [repository README](https://github.com/ArtemIyX/aven-shared#readme) for themes and customization.
